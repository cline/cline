This tutorial walks through the [code-review-bot example](https://github.com/cline/cline/tree/main/apps/examples/code-review-bot) from the SDK repository. By the end, you'll understand how to combine custom tools, system prompts, completion lifecycle, and event streaming into a real application.

## What It Builds

The example opens a dashboard where you can enter a GitHub pull request URL. It fetches the diff, streams findings as the agent reviews the changes, and lets you copy the finished review.

## Prerequisites

- Node.js 22+ and Bun
- A Cline API key
- A GitHub pull request URL. A public PR works without a GitHub token.

## Get the Code

```bash
git clone https://github.com/cline/cline.git
cd cline/apps/examples/code-review-bot
bun install
bun run build:sdk
```

## Run It

Set `CLINE_API_KEY` in your shell, then start the dashboard:

```bash
bun dev
```

Open [http://localhost:3457](http://localhost:3457), paste the PR URL, and select **Run Review**. When the run finishes, select **Copy Review** to copy the findings and summary.

## How It Works

The [example source](https://github.com/cline/cline/blob/main/apps/examples/code-review-bot/src/index.ts) defines the agent in `runAiReview`. Its system prompt tells the agent to read more context when needed, record individual findings, and submit a final summary. Each step uses a tool:

| Tool | What it does |
| --- | --- |
| `get_file_context` | Reads a file at the PR’s head commit when a diff hunk needs context. |
| `add_review_finding` | Validates the file, line, severity, and other finding fields with a Zod schema. Stores the finding and sends it to the dashboard. |
| `submit_review` | Records the summary and approval recommendation. Its `lifecycle: { completesRun: true }` setting ends the run. |

### Streaming a finding

The server opens a stream of server-sent events when the browser requests a review. Inside the `add_review_finding` tool, the same finding goes to the results array and to the browser:

```typescript
const finding = {
  id: `F-${String(findings.length + 1).padStart(2, "0")}`,
  ...input,
};
findings.push(finding);
send({ type: "finding", finding });
```

The dashboard can display each finding while the review is still running. Once `agent.run()` finishes, the server sends a final `done` event with the findings, summary, and token usage.
