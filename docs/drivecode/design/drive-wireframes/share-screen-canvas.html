In-repo canvas · share-screen slice of cline-drivemode (Drive / Drivecode)
Share screen · three-layer map

How Drive "shares a screen": an agent shares by emitting typed work events (edit / command / test / plan) that render as cards on a shared surface called Spotlight — the wire protocol still calls it stage. The hub daemon is the single writer of room state; clients mutate through call_* ops and receive room.snapshot broadcasts. This canvas maps that slice across three layers — plans & vision, product docs, and code & status — draws plan → code edges, and marks the three gaps that keep the live loop from running. Click any node to trace its edges; click a legend chip to filter by maturity.
