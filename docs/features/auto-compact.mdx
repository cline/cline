When your conversation approaches the model's context window limit, Cline compacts it to free up space and keep working. You can also compact on demand with `/compact`.

## How It Works

Before each model request, Cline estimates the size of the request (system prompt, tools, and conversation). When the estimate reaches **90% of the model's input limit**, it compacts the conversation before sending the request.

The input limit is the model's reported maximum input tokens, capped at its context window. If a model only reports a context window, Cline keeps a 10% margin and uses the rest. If the model reports neither, auto compaction does not run, because a guessed limit could compact a brand-new session.

A compaction divider in the chat shows the progress and result, for example `Context compacted · 150k → 40k tokens · 80 → 12 messages`.

## Strategies

| Strategy | What it does | Extra model request |
| --- | --- | --- |
| **Agentic** (default) | Asks the model to summarize the older part of the conversation and keeps roughly the most recent 20k tokens verbatim. Later compactions fold new messages into the previous summary. | One summarization request to your current provider and model |
| **Basic** | Folds the history without a model call. Your typed prompts always survive, the latest turn keeps its newest messages, and dropped work is replaced with short summaries attached to the surviving prompts. | None |

If an agentic compaction fails, Cline falls back to the basic strategy for that compaction so the task can continue.

### Where to configure it

- **VS Code / JetBrains**: Settings → Features. **Auto Compact** turns automatic compaction on or off (on by default). **Auto Compact Strategy** chooses **Agentic** or **Basic**.
- **CLI**: `--compaction agentic|basic|off` (default: `agentic`). See the [CLI reference](/cli/cli-reference).
- **Cline Desktop**: auto compaction is always on and uses the agentic strategy.

## Manual compaction

Type `/compact` in the chat to compact the current conversation right away. The target is about half of the current conversation size. Manual compaction is refused while a response is in progress; wait for the turn to finish or stop it first.

- **VS Code / JetBrains**: `/compact`, `/smol`, and `/newtask` all run a real compaction. The **Compact Task** button in the context window indicator does the same.
- **CLI**: `/compact` in the TUI.
- **Cline Desktop**: `/compact`. While it runs, the composer shows **Compacting... click Stop to cancel**, and sending another message is refused until the compaction finishes or is stopped.

## Stopping a compaction

Stopping the agent also stops a compaction that is in flight:

- **CLI**: press `Escape`. The divider shows **Compaction cancelled**.
- **Cline Desktop**: click **Stop**. Cline shows **Compaction cancelled.**
- **VS Code / JetBrains**: cancelling the task cancels an auto compaction in progress; the divider shows **Compaction cancelled**.

The conversation is left as it was before the compaction started.

## Context window overflow

Token estimates can under-count dense content such as minified code or long tool output. If the provider rejects a request because the context window was exceeded, Cline compacts the conversation and retries the request once. The chat shows **context window exceeded — compacting and retrying**. If the retry is also rejected, the task stops with an error.

<Tip>
Auto Compact works especially well for long-running tasks. Structured task lists can help maintain progress across compactions so Cline can stay on track across multiple context windows.
</Tip>

## Cost Considerations

With the agentic strategy, each compaction makes one additional request to your current model, shown in the chat like any other API call. The basic strategy makes no extra request.

## Restoring Context

You can use [checkpoints](/core-workflows/checkpoints) to restore your task state from before a compaction occurred. You never truly lose context since you can always roll back.

Editing a message before a compaction works similarly, restoring the conversation to that point.
