MiniMax provides MiniMax-M3.1-Flash and MiniMax-M3, with 1M context windows and automatic prompt caching.

**Website:** [https://www.minimax.io/](https://www.minimax.io/)

### Get API Credentials

1.  **Sign Up/Sign In:** Go to the [MiniMax Platform](https://www.minimax.io/platform). Create an account or sign in.
2.  **Navigate to API Keys:** Access the API key section.
3.  **Create a Key:** Generate a new API key.
4.  **Copy the Key:** Copy the API key immediately and store it securely.

### Configuration in Cline

> See [Authorization & Model Selection](/getting-started/authorizing-with-cline#menu).

1.  **Open Cline Settings:** Click the settings icon (⚙️) in the Cline panel.
2.  **Select Provider:** Choose "MiniMax" from the "API Provider" dropdown.
3.  **Enter API Key:** Paste your MiniMax API key.
4.  **Select Provider Model:** Choose your desired model from the "Model" dropdown.

### Tips and Notes

-   **Default Model:** MiniMax-M3.1-Flash. MiniMax-M3 remains available.
-   **Context and Output:** Both models support a 1M context window. The [Anthropic-compatible API](https://platform.minimax.io/docs/api-reference/text-chat-anthropic.md) accepts `max_tokens` from 1 through 524,288 and recommends 131,072.
-   **Flash Thinking:** Always adaptive. Choose `low`, `medium`, `high`, `xhigh`, or `max` effort; the default is `max`. Flash cannot disable thinking and does not accept `service_tier`.
-   **M3 Thinking:** Supports adaptive or disabled thinking; effort does not affect M3.
-   **Input:** Both APIs support text, image, and video. Cline's Anthropic adapter currently exposes text and image input; MiniMax video blocks are not supported by this adapter.
-   **Caching:** Automatic prompt caching is supported; explicit Anthropic `cache_control` markers are not.
-   **Pricing:** Flash costs $0.15 input / $0.60 output / $0.015 cache read per million tokens. M3 Standard costs $0.30 / $1.20 / $0.06 at input lengths up to 512K, and $0.60 / $2.40 / $0.12 above 512K. M3 Priority costs 1.5 times Standard; Cline's flat estimates use the Standard rate for inputs up to 512k and can underestimate higher-context or Priority requests. The published threshold is retained as `512k` because the pricing page does not define its integer expansion. See [official pricing](https://platform.minimax.io/docs/pricing/overview).
