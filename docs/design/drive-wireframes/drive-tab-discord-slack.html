What this decides

  1. Drive is a hub activity next to Chat, holding channels + call rooms, not only a header toggle on Chat.
  2. Agents are first-class roster members (Discord voice nested list + Slack huddle presence).
  3. Click a participant → that agent's private transcript. Click the call → room thread.
  4. Address chips / hotkeys set addressSet to one | many | everyone before send.
  5. Stage is a last-event-wins projection over hub session events. Either side can hold it.

Chrome fidelity

The left rail is the hub activity bar (Home / Sessions / Chat / Drive / Agents / MCP / Settings), not a Discord server rail — Drive is one more activity in the product you already have. The composer mirrors apps/cline-hub/src/webview/src/components/Composer.tsx: input line first, then a tool row carrying attach, provider:model, thinking level, and the mode segment, with submit on the right. The call strip mirrors drive/DriveCallChrome.tsx with brand violet in place of its placeholder amber. UI type is Schibsted Grotesk, the font the hub webview actually ships.

Variants

Discord-leaning keeps the right-hand member sidebar, so roster is answerable twice: nested under the call and listed in full. Slack-leaning drops it, widens the channel list, and adds the drop-in huddle banner. Both keep the hub rail.

Violet edge (default) spends the accent on a left edge and a text tint over a raised surface. Violet fill puts #9F58FA behind the selected row. Send stays filled in both, so the only thing changing between them is selection.

Palette, type, radius, and hairline values come from CLINE-BRAND-TOKENS.md, extracted from the live site. Discord blurple is deliberately absent — we steal the IA, not the palette.
