Pair-call Drive inside Cline. Hub is the single room writer. @cline/drive is the portable kernel. This page is the durable twin of the old out-of-repo Cursor overview canvas.

Architecture

Boundaries

  • Hub daemon ws://127.0.0.1:25463 owns room writes
  • Webview / CLI project events; they do not open a second daemon
  • Stage is events-first; WebRTC comes later

Domain

  • Room snapshot + Drive events in @cline/shared
  • reduceRoom / projectStage in @cline/drive
  • RosterPack is seating, not Cline Team
