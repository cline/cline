# Bedrock Coder modifications

Copyright 2026 FFFalexgo

Bedrock Coder is an independent derivative of Cline. The fork removes
non-Amazon-Bedrock providers and Cline-hosted commercial services, replaces the
extension, SDK, protobuf, command, settings, storage, and environment identity,
and adds local-first Bedrock configuration, diagnostics, approvals, history,
checkpoints, teams, worktrees, and Kanban integration.

Changed files remain available through the Git history. Unchanged upstream
code and retained notices remain copyright their respective owners. See
[NOTICE](NOTICE) and [LICENSE](LICENSE).
