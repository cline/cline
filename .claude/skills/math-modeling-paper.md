# 数学建模论文生成 Skill

根据赛题和数据，自动完成：读题 → 建模 → 求解 → 撰写论文 → 编译 PDF

## 使用方法

用户提供：
1. 赛题文件（PDF/DOCX/图片）
2. 数据文件（Excel/CSV）
3. 竞赛信息（可选）：队伍编号、题号、学校、队员

## 执行流程与进度追踪

标准 7 步流程，每步完成后显示进度：

```
1. 读题分析 ⏳：待完成
2. 制定求解计划 ⏳：待完成
3. 求解问题一 ⏳：待完成
4. 求解问题二 ⏳：待完成
5. 求解问题三 ⏳：待完成
6. 撰写论文 ⏳：待完成
7. 编译排版 ⏳：待完成
```

### 步骤 1：读题分析 📖

**目标：** 深入理解赛题要求，提取关键信息

**操作：**
1. 创建工作区目录结构：
   ```
   workspace/
   ├── 题目/          # 赛题文件
   ├── 数据/          # 数据文件
   ├── 求解/          # 代码、图表、中间结果
   └── 论文/          # LaTeX 源码和 PDF
   ```

2. 读取赛题文件（PDF/DOCX/图片）
   - 提取完整文本内容
   - 识别问题背景和要求
   - 分解子问题（通常 3-4 个）
   - 保存到 `题目/题目内容.txt`

3. 数据探索
   - 读取所有数据文件（Excel/CSV）
   - 统计行列数、字段类型
   - 计算基本统计量（均值、标准差、范围）
   - 检查缺失值和异常值
   - 保存数据摘要到 `数据/数据摘要.txt`

**输出：**
- `题目/题目内容.txt`：完整题目文本 + 问题分解
- `数据/数据摘要.txt`：数据基本信息和统计特征
- 问题理解报告（在控制台输出）

**完成标志：** ✅ 读题分析完成，进入步骤 2

### 步骤 2：制定求解计划 📋

**目标：** 为每个子问题设计建模方案和求解策略

**操作：**
1. 分析每个子问题的特点
   - 问题类型（优化/预测/分类/评价/图论/统计）
   - 输入输出要求
   - 约束条件
   - 评价指标

2. 选择合适的模型方法
   - **优化问题**：线性规划、非线性规划、整数规划、遗传算法
   - **预测问题**：时间序列、回归分析、LSTM/GRU
   - **分类问题**：逻辑回归、决策树、随机森林、SVM
   - **评价问题**：AHP、熵权法、TOPSIS、灰色关联
   - **图论问题**：最短路径、最小生成树、网络流
   - **统计分析**：假设检验、方差分析、相关性分析

3. 规划求解步骤
   - 数据预处理方案
   - 模型构建流程
   - 参数优化方法
   - 结果验证策略

4. 创建求解计划文档
   - 保存到 `求解/求解计划.md`
   - 包含每个问题的方法、步骤、预期输出

**输出：**
- `求解/求解计划.md`：完整的建模和求解方案

**完成标志：** ✅ 求解计划制定完成，进入步骤 3

### 步骤 3/4/5：求解问题一/二/三 🧮

**目标：** 针对每个子问题完成建模、编程、求解、可视化

**操作：** （以问题一为例，问题二/三类似）

1. **创建问题目录**
   ```
   求解/问题一/
   ├── solve.py              # 主求解代码
   ├── data_processed.csv    # 预处理后的数据
   ├── result.json           # 计算结果
   ├── model_params.json     # 模型参数
   └── figures/              # 图表目录
       ├── fig1_data_dist.png
       ├── fig2_model_result.png
       └── fig3_validation.png
   ```

2. **数据预处理**
   - 读取原始数据
   - 清洗：处理缺失值、异常值
   - 转换：标准化、归一化、编码
   - 特征工程：提取、选择、构造特征
   - 保存处理后数据到 `data_processed.csv`

3. **模型构建**
   - 编写 `solve.py`（Python）
   - 导入必要库：numpy, pandas, scipy, scikit-learn, matplotlib
   - 实现模型算法（非伪代码，必须能运行）
   - 添加详细中文注释
   
   代码结构示例：
   ```python
   # -*- coding: utf-8 -*-
   """
   问题一：[问题标题]
   方法：[使用的模型方法]
   """
   import numpy as np
   import pandas as pd
   import matplotlib.pyplot as plt
   
   # 1. 数据加载
   # 2. 数据预处理
   # 3. 模型构建
   # 4. 模型求解
   # 5. 结果验证
   # 6. 可视化输出
   ```

4. **求解与优化**
   - 运行模型获取结果
   - 调整参数优化性能
   - 验证结果合理性
   - 计算评价指标

5. **生成可视化**
   - 每个问题至少 2-3 张图表
   - 使用学术配色（蓝色系、灰色系为主）
   - 设置：`plt.rcParams['font.sans-serif'] = ['SimHei']`（中文支持）
   - 保存为高分辨率：`plt.savefig('fig.png', dpi=300, bbox_inches='tight')`

6. **保存结果**
   - 关键数值结果保存到 `result.json`
   - 模型参数保存到 `model_params.json`
   - 结果表格保存为 CSV

**输出：**
- `求解/问题一/solve.py`：完整可运行代码
- `求解/问题一/result.json`：计算结果
- `求解/问题一/figures/*.png`：图表文件（300 DPI）

**完成标志：** 
- ✅ 求解问题一完成，进入步骤 4
- ✅ 求解问题二完成，进入步骤 5
- ✅ 求解问题三完成，进入步骤 6

### 步骤 6：撰写论文 📝

**目标：** 生成完整的 LaTeX 论文源码

**操作：**

1. **创建论文目录结构**
   ```
   论文/
   ├── main.tex              # 主文档
   ├── refs.bib              # 参考文献
   └── figures/              # 图表（从求解/复制）
   ```

2. **生成 LaTeX 主文档**（`main.tex`）
   
   使用 XeLaTeX + ctex 宏包（中文支持）：
   ```latex
   \documentclass[12pt,a4paper]{ctexart}
   \usepackage{amsmath,amssymb,graphicx,subfigure}
   \usepackage{geometry,fancyhdr,abstract}
   \geometry{left=2.5cm,right=2.5cm,top=2.5cm,bottom=2.5cm}
   
   \title{[赛题标题]}
   \author{[队伍编号] / [学校名称] / [队员姓名]}
   \date{}
   
   \begin{document}
   \maketitle
   
   \begin{abstract}
   [600-800字摘要：问题概述、建模方法、主要结果、创新点]
   \end{abstract}
   
   \textbf{关键词：}[关键词1；关键词2；关键词3；关键词4]
   
   % 正文部分...
   \end{document}
   ```

3. **标准章节结构**
   
   按以下顺序组织内容：
   
   **一、问题重述**
   - 背景介绍（200-300字）
   - 问题描述（分点列出各子问题）
   
   **二、模型假设**
   - 列出 5-8 条合理假设
   - 每条假设说明依据
   
   **三、符号说明**
   - 表格形式列出所有数学符号
   - 包括变量名、含义、单位
   
   **四、问题分析与求解**
   - 4.1 问题一分析与求解
     - 问题分析
     - 模型建立（含数学公式）
     - 模型求解
     - 结果分析（插入图表）
   - 4.2 问题二分析与求解（同上）
   - 4.3 问题三分析与求解（同上）
   
   **五、模型检验与灵敏度分析**
   - 结果验证方法
   - 参数敏感性分析
   - 误差分析
   
   **六、模型评价与推广**
   - 模型优点（3-4 点）
   - 模型缺点（2-3 点）
   - 改进方向和推广应用
   
   **参考文献**
   - 至少 5-8 篇文献
   - 使用 BibTeX 管理（`refs.bib`）
   
   **附录：程序代码**
   - 使用 `\lstlisting` 环境插入关键代码
   - 不需要全部代码，只放核心算法

4. **插入图表**
   
   从 `求解/问题X/figures/` 复制图片到 `论文/figures/`
   
   图片插入示例：
   ```latex
   \begin{figure}[htbp]
     \centering
     \includegraphics[width=0.8\textwidth]{figures/fig1.png}
     \caption{数据分布特征}
     \label{fig:1}
   \end{figure}
   ```
   
   表格示例：
   ```latex
   \begin{table}[htbp]
     \centering
     \caption{模型求解结果}
     \begin{tabular}{|c|c|c|}
       \hline
       参数 & 数值 & 单位 \\
       \hline
       ... & ... & ... \\
       \hline
     \end{tabular}
   \end{table}
   ```

5. **撰写要求**
   - 摘要：600-800 字，高度凝练问题、方法、结果
   - 数学公式使用规范 LaTeX 语法
   - 语言：学术规范，避免口语化、第一人称
   - 逻辑：先分析后建模，先理论后实证
   - 图表：清晰美观，标题完整，有编号

**输出：**
- `论文/main.tex`：完整 LaTeX 源码（1500-3000 行）
- `论文/refs.bib`：参考文献数据库
- `论文/figures/`：所有图表文件

**完成标志：** ✅ 论文撰写完成，进入步骤 7

### 步骤 7：编译排版 🎯

**目标：** 将 LaTeX 源码编译为最终的 PDF 论文

**操作：**

1. **环境检查**
   - 确认已安装 TeX 发行版（TeX Live / MiKTeX / TinyTeX）
   - 确认 xelatex 和 bibtex 命令可用
   - 检查中文字体是否正常

2. **编译命令**
   ```bash
   cd 论文/
   xelatex main.tex          # 第一次编译，生成 .aux 文件
   bibtex main               # 处理参考文献
   xelatex main.tex          # 第二次编译，插入参考文献
   xelatex main.tex          # 第三次编译，完善交叉引用
   ```
   
   **为什么编译 3 次？**
   - 第 1 次：生成基本文档和辅助文件
   - 第 2 次：插入参考文献和引用
   - 第 3 次：更新所有交叉引用和页码

3. **错误处理**
   
   如果编译失败，检查：
   - 缺少宏包：运行 `tlmgr install <package>` 安装
   - 中文字体：确认 ctex 宏包正确配置
   - 图片路径：检查 `\includegraphics` 路径是否正确
   - 语法错误：查看 `.log` 文件定位问题
   - 参考文献：检查 `refs.bib` 格式

4. **质量检查**
   
   打开生成的 `main.pdf`，检查：
   - ✅ 页数：15-25 页为佳（少于 10 页或多于 30 页需调整）
   - ✅ 排版：段落对齐、行距合适、无溢出
   - ✅ 图表：清晰显示、标题完整、编号正确
   - ✅ 公式：显示正常、编号连续
   - ✅ 中文：无乱码、字体美观
   - ✅ 参考文献：格式统一、引用正确
   - ✅ 页码：从正文第 1 页开始编号

5. **生成最终版本**
   
   如果一切正常：
   - 将 `main.pdf` 重命名为规范格式：`[队伍编号]_[题号].pdf`
   - 复制到输出目录：`workspace/论文/[队伍编号]_[题号].pdf`
   - 可选：生成压缩包包含代码和数据

**输出：**
- `论文/main.pdf`：最终论文（15-25 页，文件大小 2-5 MB）
- 编译日志：`main.log`（用于错误排查）

**完成标志：** ✅ 编译排版完成，论文生成成功！

## 继续模式

如果任务中断，继续时：
1. 先 `ls 求解/` 检查已完成的问题
2. 只处理未完成的部分
3. 不要重新读题或重做已完成的问题

## 修改模式

用户要求修改时：
- 不执行读题、求解流程
- 直接定位相关文件并修改
- 修改后重新编译检查

## 重要约束

1. **禁止访问工作区之外的路径**
2. **禁止修改 题目/ 和 数据/ 目录**（除非首次读取）
3. **Python 代码必须能实际运行**（不要伪代码）
4. **图表必须实际生成**（不要占位符）
5. **LaTeX 必须能成功编译**

## 常用模型方法

根据问题类型选择：

- **优化问题**：线性规划、非线性规划、整数规划、遗传算法
- **预测问题**：时间序列、回归分析、神经网络
- **分类问题**：逻辑回归、决策树、SVM、随机森林
- **评价问题**：层次分析法（AHP）、熵权法、TOPSIS
- **图论问题**：最短路径、最小生成树、网络流
- **统计分析**：假设检验、方差分析、相关性分析

- ✅ 论文表达流畅、逻辑严谨
- ✅ 代码规范、注释完整
- ✅ 结果合理、有验证
